## Instrucciones de Instalación

1. Descarga `VoltSetup-1.0.4.exe`.
2. Ejecuta el instalador.
3. Si Windows SmartScreen muestra «Windows protegió su PC»:
   - Haz clic en **«Más información»**.
   - Haz clic en el botón **«Ejecutar de todas formas»**.
4. Confirma los permisos de Administrador cuando Windows lo solicite.
5. Sigue los pasos del asistente para completar la instalación.
